# Data dictionary

| Field | Definition |
|---|---|
| year | Calendar year used as join key. |
| chocolate_index | ONS chocolate CPI index, 2015=100. |
| confectionery_index | ONS confectionery CPI index, 2015=100. |
| minimum_wage | Headline National Living Wage hourly rate. |
| freddo_price_pence | Retained Freddo price in pence. |
| minutes_to_buy_freddo | Minutes of minimum-wage work required to buy one Freddo. |
| chocolate_index_growth | Year-on-year chocolate-index percentage change. |
| minimum_wage_growth | Year-on-year minimum-wage percentage change. |
